      Paste straight into Gmail / Outlook / Apple Mail
    

    

  


  
  

    

      

      
Gmail

      
    
        
  1. Click Copy HTML above for the variant you want.
    2. 
        
  2. Open Gmail → Settings (⚙) → See all settings.
    3. 
        
  3. Scroll to Signature → Create new.
    4. 
        
  4. Click in the signature editor, then ⌘+V (or Ctrl+V) to paste.
    5. 
        
  5. Scroll down → Save Changes.
    6. 
      

    

    

      

      
Outlook

      
    
        
  1. Open the variant's signature-*.html file in your browser.
    2. 
        
  2. Select the whole rendered signature & copy (⌘+A → ⌘+C).
    3. 
        
  3. Outlook → File → Options → Mail → Signatures….
    4. 
        
  4. Click New, name it MizanQuant, paste into the editor.
    5. 
        
  5. Set default signature → OK.
    6. 
      

    

    

      

      
Apple Mail

      
    
        
  1. Open the variant's signature-*.html file in Safari.
    2. 
        
  2. Select all (⌘+A) & copy.
    3. 
        
  3. Mail → Settings → Signatures → +.
    4. 
        
  4. Paste; uncheck Always match my default message font.
    5. 
        
  5. Drag your new signature onto the relevant account.
    6.
